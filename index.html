Windows setup in 3 easy steps.

Download the setup ZIP, extract it, then open the Windows .exe file. No complicated process.

1

Download the POS file

Press the button below to open the official Google Drive download. Save the ZIP file to your Windows PC, normally in Downloads.

Download Windows POS
2

Extract the ZIP

Open your Downloads folder. Right-click the ZIP file and choose Extract All…. Select a folder and press Extract.

Downloads → ZIP → Extract All…
3

Open the .exe

Open the new extracted folder. Find the Windows setup/application file ending in .exe and double-click it to start Cloud POS.

Extracted folder → .exe → Double-click
Windows security note: If Windows asks whether you trust the app, only continue when the file came from your official Noir Cloud download. If SmartScreen appears, review the publisher and file source before choosing to run it.
